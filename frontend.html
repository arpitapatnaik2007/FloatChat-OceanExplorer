Built for researchers, usable by anyone

Geospatial discovery

Find floats by region, trajectory or proximity — no WMO IDs or NetCDF wrangling required.

Query-to-SQL reasoning

Natural language is translated into vetted SQL over the ARGO profile index, with QC flags respected.

Reproducible outputs

Every answer ships the query, the matched profiles and a CSV/NetCDF export you can cite.

The pipeline

  1. 01

    Ingest

    ARGO NetCDF profiles parsed into a structured Postgres index with QC metadata.

  2. 02

    Embed

    Metadata and parameter vocabularies embedded into a vector store for retrieval.

  3. 03

    Reason

    The LLM plans the query, writes guarded SQL and validates units and flags.

  4. 04

    Visualise

    Results render as float maps, depth profiles, tables and citable exports.
