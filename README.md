# 🌊 FloatChat – AI-Powered Conversational Interface for ARGO Ocean Data Discovery and Visualization

## Overview

FloatChat is an AI-powered conversational platform designed to simplify the discovery, exploration, and visualization of oceanographic data collected through the ARGO program. The system enables researchers, students, fishermen, petroleum engineers, ocean enthusiasts, policy makers, etc. to interact with complex ocean datasets using natural language queries instead of traditional data-processing tools.

By combining Artificial Intelligence, Natural Language Processing (NLP), Interactive Data Visualization, and IoT-based Ocean Monitoring Concepts, FloatChat transforms raw ARGO data into meaningful insights through an intuitive chat interface.

---

## Problem Statement

Oceanographic datasets generated by the ARGO program contain vast amounts of valuable information regarding ocean temperature, salinity, pressure, and climate-related parameters. However, accessing and interpreting this data often requires specialized technical knowledge and expertise.

FloatChat addresses this challenge by providing:

* Natural language access to ARGO datasets
* Intelligent data discovery and retrieval
* Interactive visualizations and analytics
* Simplified ocean data exploration for non-experts

## Tinkercad Prototype

The project includes a Tinkercad-based simulation representing an ocean-monitoring system.

### Components Used

* Arduino Uno
* Temperature Sensor
* LCD Display
* LEDs
* Resistors
* Breadboard

### Simulation Workflow

1. Sensors collect environmental parameters.
2. Data is transmitted to the processing unit.
3. Readings are displayed in real time.
4. AI module analyzes collected information.
5. Visual insights are generated for users.

## ARGO Program

ARGO is a global ocean observation program consisting of autonomous profiling floats that measure:

* Ocean Temperature
* Salinity
* Pressure
* Ocean Currents

These floats collect data from various ocean depths and transmit it via satellite, enabling researchers worldwide to study ocean dynamics and climate change.
